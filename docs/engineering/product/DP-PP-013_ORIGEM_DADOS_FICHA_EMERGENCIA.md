# DP-PP-013 — ORIGEM DOS DADOS DA FICHA DE EMERGÊNCIA

## Identificação

- Documento: DP-PP-013.
- Projeto: CASE-03 — PetPass AI.
- Classificação: NORMATIVO.
- Assunto: origem oficial dos dados apresentados na Ficha de Emergência.
- Grupo documental relacionado: Origem dos Dados.
- Lacunas documentais relacionadas: LD-009 — Origem dos dados do Tutor; LD-011 — Origem dos dados de Emergência.

## Contexto

Durante o CASE-03 foi deliberado que a Ficha de Emergência não constitui fonte primária de informações, mas representação institucional dos dados oficiais do PetPass AI.

A presente atividade possui exclusivamente a finalidade de transformar essas decisões aprovadas em documento normativo integrante do corpus oficial.

## Deliberação aprovada

A origem oficial das informações apresentadas na Ficha de Emergência observará obrigatoriamente as seguintes regras:

1. Todos os dados apresentados na Ficha de Emergência deverão possuir origem no cadastro oficial do PetPass AI.

2. As informações de identificação do pet deverão ser obtidas exclusivamente do respectivo cadastro oficial.

3. Os dados do tutor deverão ser obtidos exclusivamente do cadastro associado ao pet.

4. Os contatos de emergência deverão ser obtidos exclusivamente das informações cadastradas para o respectivo pet.

5. A fotografia apresentada deverá corresponder exclusivamente à fotografia vinculada ao cadastro oficial do pet.

6. A Ficha de Emergência constitui representação documental das informações oficiais cadastradas, não constituindo origem primária dos dados.

7. A consistência entre o cadastro oficial e a Ficha de Emergência deverá ser preservada.

## Restrições

É vedado:

- definir mecanismos de sincronização;
- definir tecnologias de armazenamento;
- definir banco de dados;
- definir APIs;
- definir comportamento técnico de atualização;
- criar novas regras de negócio;
- modificar qualquer documento existente;
- iniciar atividades posteriores.

## Impacto documental

Esta deliberação materializa as decisões aprovadas relativas à origem oficial das informações da Ficha de Emergência e fornece decisões explícitas para as lacunas LD-009 e LD-011.

Ela não define mecanismos de sincronização, tecnologias de armazenamento, banco de dados, APIs ou comportamento técnico de atualização e não cria novas regras de negócio.
