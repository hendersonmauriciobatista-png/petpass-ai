Projeto: CASE-03 — PetPass AI.

## Título

REPRESENTAÇÃO GRÁFICA DA IDENTIDADE DIGITAL (QR CODE)

## Deliberação

1. O QR Code representa graficamente a Key Pass.

2. O QR Code não constitui identificador independente.

3. O QR Code poderá ser regenerado sempre que necessário.

4. A regeneração do QR Code preservará integralmente a mesma Key Pass.

5. A substituição do QR Code não altera a identidade digital do Pet.
