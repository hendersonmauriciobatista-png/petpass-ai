# DP-PP-014 — COMPONENTE QR CODE DA FICHA DE EMERGÊNCIA

## Identificação

- Documento: DP-PP-014.
- Projeto: CASE-03 — PetPass AI.
- Classificação: NORMATIVO.
- Assunto: componente institucional QR Code da Ficha de Emergência.
- Grupo documental relacionado: Componente QR Code.
- Lacuna documental relacionada: LD-014 — Indisponibilidade do QR Code.

## Contexto

Durante o CASE-03 foi deliberado que o QR Code constitui representação institucional da Key Pass do pet, integrando oficialmente a Ficha de Emergência.

A presente atividade possui exclusivamente a finalidade de transformar essas decisões aprovadas em documento normativo integrante do corpus oficial.

## Deliberação aprovada

O componente QR Code da Ficha de Emergência observará obrigatoriamente as seguintes regras:

1. O QR Code constitui representação institucional da Key Pass do respectivo pet.

2. Cada Key Pass possuirá exclusivamente um QR Code correspondente.

3. O QR Code deverá ser apresentado exclusivamente na área destinada a esse componente no Modelo 4.

4. A apresentação do QR Code deverá preservar sua legibilidade.

5. O QR Code integra oficialmente a identidade documental da Ficha de Emergência.

6. A existência do QR Code não substitui a Key Pass, constituindo apenas sua representação visual.

7. Na impossibilidade de apresentação do QR Code, deverá ser utilizado exclusivamente o placeholder institucional aprovado.

## Restrições

É vedado:

- definir conteúdo interno do QR Code;
- definir padrão ou versão do QR Code;
- definir nível de correção de erros;
- definir bibliotecas, APIs ou tecnologias de geração;
- definir mecanismos de leitura;
- criar novas regras de negócio;
- modificar qualquer documento existente;
- iniciar atividades posteriores.
