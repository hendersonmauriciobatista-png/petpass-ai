## 3. Critério de auditoria

Para esta auditoria, uma deliberação correspondente somente foi considerada localizada quando seu conteúdo define explicitamente o objeto específico da lacuna. Documento que trata do mesmo componente sem definir o comportamento ausente foi registrado como documento relacionado, mas não como deliberação correspondente.

Nenhuma relação foi estabelecida por equivalência presumida, finalidade semelhante ou proximidade temática.
